# Default Quarter-Acre Layout Blueprint — v0.5

**Status:** DEFAULT DESIGN LOCK / ROTATE OR MIRROR TO FIT THE REAL PARCEL  
**Location:** Richmond, Kentucky  
**Garden footprint:** 90 ft east–west × 121 ft south–north = **10,890 sq ft (1/4 acre)**

This file converts the quarter-acre program into a usable default physical plan **without pretending it is a survey of the property**. The entire blueprint can later be rotated, mirrored, or translated onto the best sunny part of the 2-acre yard while preserving the internal relationships.

## Coordinate system

Use a simple local garden grid:
- southwest corner = `(0,0)`
- east = increasing `x`
- north = increasing `y`
- east boundary = `x=90`
- north boundary = `y=121`

The default entrance is centered on the south side near `x=45`.

## Why this shape

A 90 × 121 ft rectangle is:
- exactly one quarter acre
- wide enough for multiple garden rooms
- short enough that the greenhouse-to-far-edge walk stays reasonable
- compatible with a simple central cart path
- easy to reproduce in Open Garden Planner or any CAD/map tool

## Primary circulation

### Perimeter service strip
Reserve approximately 4 ft inside the outer edge for a mixture of:
- mower/maintenance clearance
- fence access if fencing is later needed
- drainage observation
- hose/utility access
- visual breathing room

### Main north–south spine
Reserve approximately:
- `x=43–47`
- `y=4–117`
- width: ~4 ft

This is the principal wheelbarrow/cart route.

### Main cross path
Reserve approximately:
- `y=57–61`
- `x=4–86`
- width: ~4 ft

### Secondary cross paths
Use ~3–4 ft gaps around `y=33–37` and `y=77–81` where needed.

No bed should require walking on productive soil to reach its center.

# Height and shade rules

Within each outdoor room:
- tallest tomatoes and major trellises go toward the **north side** of shorter crops where practical
- cucumber trellis should not shade peppers/eggplant unnecessarily
- greenhouse remains toward the north side by default
- pumpkin vines run outward into assigned open ground, not across the central spine
- roses keep enough open air around foliage for Kentucky humidity

## Tall-structure register

Map and label:
- greenhouse ridge
- tomato supports
- cucumber trellis
- morning-glory structure
- sweet-pea structure
- tall dahlia support

These become part of the shade map.

# Default entrance sequence

From the south entrance, the preferred experience is:

**flowers/rose foreground → central spine → kitchen garden → greenhouse/work hub**

This makes the garden attractive on arrival while keeping the most functional work area at the operational end of the main path.

## Style language

Use one repeated structural vocabulary for:
- main trellises
- greenhouse trim/details where possible
- arch/obelisk
- signs/labels
- path edging

The current strongest default remains **formal bones + cottage abundance**.

---

# What is deliberately NOT filled

Do not fill every coordinate with plants simply because the rectangle exists.

The quarter acre must include:
- airflow
- staging
- path width
- compost/material handling
- future succession space
- occasional bare/recovery ground
- a comfortable visual rhythm

Unused capacity is a feature if it prevents the garden from becoming a maintenance trap.

---

# Site-fit rule

When the actual property sketch arrives, preserve these priorities in order:
1. full sun for primary vegetables
2. drainage
3. easy water
4. greenhouse access
5. path efficiency
6. tall-structure shade control
7. disease airflow
8. aesthetics

The whole blueprint may be rotated or mirrored to achieve those priorities.
