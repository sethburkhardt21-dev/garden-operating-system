# 2026–2027 Master Implementation Checklist — v0.6

**Status:** ACTIVE IMPLEMENTATION CONTROL  
**Current date context:** September 2026  
**Garden:** Richmond, Kentucky / quarter-acre Garden OS / 16 × 24 ft greenhouse

This is the single practical build checklist. It is intentionally dependency-ordered so the project does not install finish work before water, drainage, greenhouse, and paths are settled.

Use status markers:
- `[ ]` not started
- `[~]` in progress
- `[x]` complete
- `[!]` blocked / needs decision

- [ ] Inspect after meaningful rain.
- [ ] Mark standing-water spots.
- [ ] Mark high/drained areas.

## Water
- [ ] Identify closest practical water source.
- [ ] Measure source-to-greenhouse/header distance.
- [ ] Perform timed flow test.
- [ ] Measure static/dynamic pressure if possible.

## Soil

- [ ] Submit permanent edible sample if soil differs.
- [ ] Submit rose/flower sample if soil differs.
- [ ] Submit dry-herb sample if soil differs materially.
- [ ] Do not add major amendments before results.

# PHASE 10 — first-season success criteria

By the end of 2027, success means more than yield.

The project should know:
- which cultivars tasted best
- which cultivars resisted disease best
- which beds dried fastest
- which areas stayed too wet
- actual harvest quantities
- which flowers produced the best bouquets
- which roses handled black spot pressure best
- whether the greenhouse was too hot/cold/crowded
- whether irrigation zones were correctly separated
- whether 1/4 acre felt comfortable or too labor intensive
- whether any plant counts should increase/reduce in 2028

The first season is also a measurement campaign for the permanent Garden OS.
