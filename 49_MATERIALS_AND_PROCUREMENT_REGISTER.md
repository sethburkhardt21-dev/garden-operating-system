# Materials + Procurement Register — v0.6

**Status:** PROCUREMENT LOGIC LOCKED / BRANDS, QUANTITIES, AND PRICES PARTLY SITE-DEPENDENT  
**Rule:** buy in dependency order, not excitement order.

This register prevents the project from purchasing finish materials before the site, greenhouse, water, and path geometry are stable.

## Procurement status vocabulary

- `BUY NOW` — low-regret, time-sensitive, or universally useful
- `BUY AFTER SITE FIT` — needs actual location/measurement
- `BUY AFTER MODEL SELECTED` — depends on selected greenhouse/irrigation hardware
- `WINTER ORDER` — order/reserve before spring supply pressure
- `SPRING BUY` — perishable/live/seasonal item
- `OPTIONAL` — style/automation upgrade
- `DO NOT BUY YET` — high rework risk

# B. Greenhouse package

## BUY AFTER SITE + MODEL SELECTED

### Structure
- 16 × 24 ft greenhouse kit/frame
- manufacturer-approved foundation/anchor hardware
- glazing package
- doors
- roof/side vents
- gutters/downspouts if compatible

### Ventilation
- exhaust fan package sized to approximately 3,100–3,900 CFM **effective installed summer capacity**, then verified against manufacturer/system losses
- intake louver/opening package sized to fan free-air requirements
- 2 circulation/HAF fans or equivalent circulation solution
- thermostat/controller
- manual emergency vent capability
- removable shade-cloth attachment points

### Water
- greenhouse shutoff
- hose/wand tap
- filter/regulator for greenhouse micro-irrigation
- internal subzone valves

### Electrical
- service/conduit/outlets/controls as required by the final electrical plan and applicable code
- GFCI/wet-location protections where required

### Monitoring
- min/max thermometer
- temperature/RH sensor
- optional remote high/low temperature alert

## DO NOT SUBSTITUTE
A gadget-heavy greenhouse with weak ventilation is not an upgrade.

# D. Bed infrastructure

## Selective raised-bed materials
Buy only for beds where raised construction has a clear reason:
- drainage
- accessibility
- soil control
- polished entrance/kitchen-zone appearance

Potential first raised modules:
- K01–K08 high-frequency kitchen beds

## In-ground by default
- R1–R4 rotation blocks
- F01 pumpkin/sprawling zone
- FL01–FL03 flower blocks unless soil/access argues otherwise

## Soil inputs
Do not bulk-purchase lime, sulfur, phosphorus, potassium, or other amendments before soil-test interpretation.

Low-regret organic-matter additions still need reasonable quality/source and should not be used to bury drainage problems.

# K. Procurement gates before large orders

## Greenhouse order gate
- actual site chosen
- drainage acceptable
- solar/shade check complete
- water route known
- electric strategy known
- foundation/anchor plan known
- ventilation package compatible

## Irrigation order gate
- source GPM measured
- pressure known
- zone map accepted
- line distances measured

## Rose order gate
- plant positions accepted
- sun/airflow adequate
- mature width known
- disease-resistance evidence reviewed

## Bulk path/bed-material gate
- final path edges staked on the ground
- wheelbarrow/cart test completed
- buried services finalized first

# Procurement principle

The best purchase is the one that closes a known requirement without creating rework.

A quarter-acre garden does not need to be bought all at once.
