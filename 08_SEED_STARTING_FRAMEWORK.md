# Seed Starting Framework

## Start indoors — likely
- tomatoes
- peppers
- eggplant
- some cabbage cycles
- snapdragons
- some dahlias if grown from seed (tubers handled separately)
- selected flowers depending cultivar

## Usually direct sow / practical direct sow
- cucumbers (or short indoor head start)
- squash
- pumpkin
- cilantro
- cosmos
- zinnias
- morning glories
- many wildflowers

## Plant as non-seed material
- garlic = cloves
- potatoes = certified seed potatoes
- asparagus = preferably crowns/transplants
- rhubarb = crowns/divisions/transplants
- dahlias = tubers if using named varieties
- roses = nursery plant/bare root/container

## Every seed-start record must track
cultivar; source; sow date; cells; medium; temperature; germination date; germination rate; light; pot-up date; hardening start; transplant date; notes.

## Hard rule
Do not create one generic “8 weeks before frost” rule for everything. Back-calculate individually by crop/cultivar.
