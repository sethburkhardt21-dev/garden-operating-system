# Weekly Garden Routines — v0.2

**Status:** OPERATING FRAMEWORK / site-specific cadence remains provisional.

The goal is to keep maintenance predictable and prevent the garden from turning into a long emergency list.

## Daily 5-minute scan during active season
- check severe weather/frost/heat alerts
- glance at containers and newly transplanted plants
- harvest anything that becomes poor if left another day
- check whether a trellis/stem has failed
- notice sudden wilt or collapse

## Twice-weekly production walk
### Vegetables
- tomatoes: inspect lower leaves, ties, ripening fruit, cracking
- peppers/eggplant: inspect fruit load, bacterial-looking spots, pests
- cucumbers/squash/pumpkin: inspect leaf undersides, vine bases, fruit, wilting
- cabbage: inspect inner/underside leaves for caterpillars and holes
- potatoes: inspect for Colorado potato beetles and exposed tubers

### Flowers
- roses: inspect leaves for black spot and flowers for Japanese beetles
- dahlias/zinnias/cosmos: cut/deadhead, inspect support
- coneflower/Rudbeckia/daylily: remove only what the current style/ecology plan calls for

### Herbs
- basil/cilantro/parsley: harvest before quality declines
- rosemary/thyme/lavender: check drainage rather than automatically watering

## Weekly maintenance session
1. Review the Today Engine and weather.
2. Check soil moisture by hydrozone.
3. Harvest all mature produce.
4. Train/tie vertical plants.
5. Weed while weeds are small.
6. Deadhead/cut selected flowers.
7. Inspect irrigation emitters/hoses.
8. Photograph any new pest/disease issue.
9. Enter a one-paragraph journal note.
10. Update inventory only when something materially changed.

## Every 2–4 weeks during peak growth
- inspect trellis anchors and cage stability
- check mulch depth and pull mulch away from crowns/stems where necessary
- evaluate fertilizer need from plant stage + soil plan rather than calendar alone
- check paths/access for overgrowth
- compare actual plant spread with design assumptions
- review seed/plant succession opportunities

## Monthly learning review
Ask:
- what is thriving?
- what is underperforming?
- is the cause location, cultivar, weather, soil, pests, disease, irrigation, or timing?
- what task is consuming the most time?
- what could be redesigned instead of repeatedly maintained?
- what should be photographed/measured before the month ends?

## Peak-summer priority order
1. plant survival / weather protection
2. watering based on actual need
3. harvest
4. pest/disease containment
5. support/training
6. weeds before seed set
7. deadheading/style
8. optional projects

## Fall priority order
1. harvest/store mature crops
2. record disease/pest evidence
3. garlic preparation/planting at appropriate window
4. dahlia identification and winter-storage plan
5. remove/clean diseased annual-crop supports and residue
6. soil test / amendment planning
7. protect perennial infrastructure
8. update next-year rotation

## Winter priority order
1. cultivar decisions
2. seed inventory/order
3. scaled layout
4. planting calendar
5. trellis/irrigation construction
6. seed-start supplies
7. research unresolved failures
8. style projects

## Spring priority order
1. soil readiness and frost/weather
2. permanent crop establishment
3. cool-season planting
4. seed-start/transplant hardening
5. irrigation test
6. install supports before warm-season planting
7. warm-season transplanting only when conditions are appropriate

## Maintenance-budget rule
If routine work repeatedly exceeds the user's available time, do not respond only by making a longer checklist. Redesign:
- fewer but better-placed plants
- stronger permanent supports
- drip irrigation
- thicker appropriate mulch
- larger repeated flower masses
- better paths/access
- simpler container count

The garden should become easier to run as the system learns.
