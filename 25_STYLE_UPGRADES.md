# Style Points

## ESSENTIAL
- one consistent material for major trellises/supports
- clean bed edges
- deliberate mulch
- legible plant labels
- no loose hose sprawled through primary view/path
- repeat flower groups rather than one-each randomness

## POLISHED
- matching tomato cages/stakes
- obelisk/arch for one ornamental vine
- red roses as repeated focal points
- coordinated containers
- dedicated cut-flower strip
- simple bench or standing pause point
- concealed drip lines
- attractive label system

## THIS LOOKS RIDICULOUSLY GOOD
- formal visual axis terminated by a red rose/obelisk focal point
- warm low-voltage path/accent lighting
- custom cedar/metal trellis language repeated throughout
- herb border near harvest access
- layered perennial + annual flower border with planned bloom waves
- beautiful rain-barrel screen
- small harvest/washing station
- labeled garden map mounted near entrance
- seasonal bouquet plan using the flowers already on the list

## Rule
No style upgrade may materially reduce sunlight, airflow, irrigation access, or harvest access.
