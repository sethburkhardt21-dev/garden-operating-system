## Greenhouse direction

See `38_GREENHOUSE_PLAN.md`.

The default 16 × 24 ft greenhouse is large enough for:
- seed starting
- transplant production
- hardening/staging
- shoulder-season herbs/greens
- selected protected tomatoes/peppers/cucumbers
- propagation
- potting/work space

It is not assumed to be fully heated all winter. Kentucky greenhouse guidance makes both cold-season heat and hot/humid-season ventilation important design considerations. The greenhouse is therefore designed around excellent venting first, with heat added only to the level actually needed.
