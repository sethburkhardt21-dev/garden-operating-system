# Flower Design

## Visual language
“Abundant but intentional.”

Use repetition:
- repeat 2–4 anchor flowers instead of one of everything everywhere
- repeat the same trellis material
- repeat edge plants
- repeat red-rose focal color

## Structure
### Permanent bones
red roses, coneflower, black-eyed Susan, daylily, hardy daisy selection, possibly hardy geranium.

### Seasonal volume
dahlias, zinnias, cosmos, marigolds, snapdragons, impatiens.

### Vertical moments
morning glory in warm season; sweet peas in cool season.

## Continuous-color concept
Cool season: snapdragons + sweet peas  
Early/mid warm season: roses + annuals beginning  
Peak summer: zinnias + dahlias + cosmos + marigolds  
Late season: dahlias + zinnias + coneflower + Rudbeckia + selected cosmos

Exact timing becomes site/cultivar-specific later.
