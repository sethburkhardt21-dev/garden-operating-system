# Wildflower Tub Mini-Project

## Intent
A separate container that looks like a joyful random jumble but is actually engineered.

## Design variables
- tub dimensions
- drainage holes
- soil depth
- daily sun
- wind
- irrigation access

## Mix architecture
Aim for:
- low edge layer
- medium flowering body
- a few airy/tall accents
- staggered bloom periods
- pollinator value
- compatible moisture needs

## Safety gates before adding any species
- confirm regional appropriateness
- screen invasive/aggressive species
- verify whether it can escape the tub via seed
- verify mature height
- verify annual/perennial behavior
- avoid anonymous “national wildflower” mixes until every ingredient is known

## Style rule
Random-looking placement is allowed.
Random species selection is not.
